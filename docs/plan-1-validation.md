# Plan 1 — livraison et validation

Implémentation FO du plan approuvé le 1er octobre 2026. L’apparence et la composition des cartes sont conservées. La navigation privilégie collection, boosters, wishlists et catalogue ; les corrections de mise en page servent à rendre les actions accessibles. Aucun skill UI/UX n’a été utilisé pour cette livraison.

## Contrat et données

- Swagger fourni : **134 opérations, 106 chemins, 101 schémas**, copie canonique dans `docs/contracts/api.openapi.json`, types dans `src/lib/api/schema.ts` et matrice dans `docs/api-fo-coverage.md`.
- Les lectures API sont la référence après mutation/reconnexion. Le SSE déclenche des rafraîchissements ciblés ; les réponses d’une ancienne session sont ignorées.
- Les identifiants d’articles, exemplaires, joueurs et packs restent internes aux requêtes ; les choix exposent des noms/titres.
- Une vente immédiate reste compatible avec un échange ; protection/enchère/échange utilisent les engagements correspondant à chaque action.
- Aucun code de secours complet ne rejoint la session persistée ou un brouillon. Les mocks et tests utilisent des codes de démonstration.

## Validation

La validation se fait avec `PUBLIC_API_MOCK_ENABLED=true`, un serveur Vite HTTPS local sur 5180, et les appels vers l’API de production bloqués dans les scripts Playwright. Les scénarios couvrent compte neuf, collections nombreuses (145 exemplaires), erreurs, conflits, champs omis, dates relatives, stock limité et propriétaire de guilde. Les captures de cartes/modales, lots de boosters et avatars sont dans le dossier temporaire `encyclomestre-plan-one`.

## Limites de livraison

Aucune écriture de test en production, modification backend, installation de dépendance, publication ou push. Le commit local demandé regroupe la livraison du Plan 1. La passkey virtuelle ne valide pas une biométrie réelle ni Cloudflare en production. Les textes légaux définitifs et la refonte graphique restent à compléter séparément. Aucun marché global de ventes immédiates ni historique des signalements n’est inventé hors Swagger.
