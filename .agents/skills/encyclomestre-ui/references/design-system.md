# L'Alchimie Sombre

- Use `bg-background` / `bg-card` as ink and cabinet grounds; use `primary` for copper; preserve emerald as a subtle secondary state.
- Use massive serif uppercase headings, editorial italic body copy, and compact mono telemetry.
- Use square corners. Prefer fine copper borders; reserve double borders for major frames, registries, and overlays.
- Cards use an external dark frame and an inner protective frame. Full-art remains a supported variant.
- Keep mobile layouts touchable: controls wrap or stack, hover-only content must be openable with touch, and fixed panels must not hide final content.
- Preserve card ratio and shared `CardTile` composition across catalogue and collection.
- Tag colors are data. Render them as small bordered mono labels; overflow labels use a `+n` details control that works with hover and touch.
